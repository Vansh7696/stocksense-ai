## 1. Express API Gateway Endpoints

### 1.1 `GET /api/stocks/:id/predictions`

Retrieves multi-horizon directional predictions for a specified Indian equity.

#### Request Overview:
- **Method**: `GET`
- **Route**: `/api/stocks/:id/predictions`
- **Authentication**: **Required** (`auth` middleware). Supports `Authorization: Bearer <jwt>` or signed HTTP-only session cookie.
- **Rate Limit**: **30 requests per minute** per user ID (or client IP fallback).
- **Cache TTL**: **300 seconds** (Redis).

#### Parameters:
| Type | Name | Data Type | Required | Description | Example |
| :--- | :--- | :--- | :---: | :--- | :--- |
| **Path** | `:id` | `String` | **Yes** | Stock UUID, Upstox instrumentToken, or Symbol | `RELIANCE` or `cd5eeffc-e9b2-44d0-9817-1b45e8635812` |
| **Query** | `exchange` | `String` | Optional | Exchange filter (`NSE` or `BSE`). Required if symbol exists on both exchanges. | `NSE` |
| **Query** | `horizon` | `Integer` | Optional | Single horizon filter (`1`, `3`, or `5`). If omitted, returns all 3 horizons. | `1` |

#### Rate Limit Response Headers:
- `X-RateLimit-Limit`: `30`
- `X-RateLimit-Remaining`: Remaining request quota in current 60s window.
- `X-RateLimit-Reset`: Unix timestamp when the rate limit window resets.
- `Retry-After`: Seconds to wait when rate limited (e.g. `60`).

### 1.2 Error Responses & HTTP Status Taxonomy

| HTTP Status | Error Code | Trigger Condition | Example Payload |
| :---: | :--- | :--- | :--- |
| **400** | `INVALID_HORIZON` | Query param `horizon` is not 1, 3, or 5 | `{"success": false, "error": {"code": "INVALID_HORIZON", "message": "Invalid horizon filter \"4\". Allowed forecast horizons: 1, 3, 5 trading days."}}` |
| **400** | `INVALID_EXCHANGE` | Query param `exchange` is not NSE or BSE | `{"success": false, "error": {"code": "INVALID_EXCHANGE", "message": "Invalid exchange filter \"NASDAQ\". Allowed: NSE, BSE"}}` |
| **400** | `INSUFFICIENT_HISTORICAL_DATA` | Stock has fewer than 200 daily sessions | `{"success": false, "error": {"code": "INSUFFICIENT_HISTORICAL_DATA", "message": "Insufficient historical daily candle data for \"ABC\". At least 200 trading sessions are required for algorithmic feature warm-up (found 50)."}}` |
| **401** | `UNAUTHORIZED` | Missing or invalid JWT Bearer token | `{"success": false, "error": {"code": "UNAUTHORIZED", "message": "Authentication required. Missing session cookie or Authorization header."}}` |
| **404** | `STOCK_NOT_FOUND` | Stock identifier not found in PostgreSQL | `{"success": false, "error": {"code": "STOCK_NOT_FOUND", "message": "Stock not found with identifier: \"NONEXISTENT\""}}` |
| **409** | `AMBIGUOUS_STOCK_IDENTIFIER` | Symbol matches multiple exchanges without `?exchange=` | `{"success": false, "error": {"code": "AMBIGUOUS_STOCK_IDENTIFIER", "message": "Ambiguous stock symbol \"RELIANCE\". Found 2 matching instruments across exchanges/segments. Please specify the \"exchange\" query parameter...", "details": {"matches": [...]}}}` |
| **429** | `TOO_MANY_PREDICTION_REQUESTS` | User exceeds 30 requests within 60 seconds | `{"success": false, "error": {"code": "TOO_MANY_PREDICTION_REQUESTS", "message": "Prediction rate limit exceeded. You may generate up to 30 predictions per minute. Please try again in 60 seconds."}}` |
| **503** | `ML_SERVICE_UNAVAILABLE` | FastAPI microservice is offline or unreachable | `{"success": false, "error": {"code": "ML_SERVICE_UNAVAILABLE", "message": "Machine learning microservice is unavailable at http://localhost:8000."}}` |
| **504** | `ML_SERVICE_TIMEOUT` | FastAPI microservice exceeds 5000ms SLA | `{"success": false, "error": {"code": "ML_SERVICE_TIMEOUT", "message": "Machine learning microservice timed out after 5000ms."}}` |

### 1.4 Horizon Label Semantics & Discrepancy Note

Consumers of the prediction API should note the following field semantics:
- **`horizonDays`**: Integer representing the target horizon in trading sessions ($1, 3, 5$).
- **`horizonLabel`**: Human-readable label generated by `backend/src/controllers/prediction.controller.js`.
  - For $h=1$: `"1 Trading Day (Next Session Close)"`
  - For $h=3$: `"3 Trading Days (Multi-Session Trend)"`
  - For $h=5$: `"5 Trading Days (1 Calendar Week)"`
- **Frontend Display Nuance**: The frontend card component (`HorizonPredictionCard.jsx`) displays `"5 Trading Sessions"` as its subtitle rather than `"1 Calendar Week"`, reflecting the fact that 5 trading sessions may span more than 7 calendar days during weeks with market holidays.

## 2. Python FastAPI Upstream Microservice Endpoints

The internal ML service (`ml-service`) exposes high-performance computational endpoints:

### 2.1 `POST /api/predict/multi-horizon`
- **Description**: Consumes 200–300 ascending OHLCV daily candle dictionaries, computes 23 technical indicators, and returns multi-horizon predictions simultaneously.
- **Request Body Schema (`MultiHorizonInferenceRequest`)**:
  ```json
  {
    "symbol": "RELIANCE",
    "exchange": "NSE",
    "candles": [
      {
        "timestamp": "2025-08-15T09:15:00.000Z",
        "open": 2450.5,
        "high": 2480.0,
        "low": 2440.0,
        "close": 2475.25,
        "volume": 5210400
      }
    ],
    "horizons": [1, 3, 5]
  }
  ```
- **Validation Rules**:
  - `candles` must contain $\ge 200$ items.
  - `open`, `high`, `low`, `close`, and `volume` must be positive finite floats.
  - `horizons` must be a subset of $\{1, 3, 5\}$.

### 2.2 `GET /health` & `GET /api/health`
- **Description**: Lightweight health and readiness probe.
- **Output**:
  ```json
  {
    "status": "UP",
    "service": "stocksense-ml-service",
    "version": "1.0.0",
    "uptime_seconds": 36958.3
  }
  ```
